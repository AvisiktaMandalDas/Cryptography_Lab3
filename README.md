# Cryptography_Lab3
The Implementation of the RSA Algorithm demonstrates how public-key cryptography can be used to achieve secure communication. RSA is an asymmetric cryptographic system that employs two keys: a public key for encryption and a private key for decryption. The process begins with the generation of two large prime numbers from which the keys are derived. Once the keys are established, a plaintext message can be transformed into ciphertext using the public key. The corresponding private key is then applied to the ciphertext to recover the original message. This mechanism ensures that only the intended recipient, who possesses the private key, can decrypt the information, thereby maintaining the confidentiality of communication.

The Implementation of an RSA-based Digital Signature System illustrates how RSA can also be used for authentication, integrity verification, and non-repudiation. Instead of encrypting the entire message, a condensed hash value representing the message is created. This hash is then encrypted using the sender’s private key to form the digital signature, which is transmitted along with the original message. On the receiver’s side, the hash of the received message is computed independently and compared with the value obtained by decrypting the digital signature using the sender’s public key. A successful match confirms that the message has not been modified during transmission and verifies the identity of the sender. Since the signature can only be generated with the sender’s private key, it also prevents the sender from denying authorship of the message.
